# 🌍 Cities Frontend SPA (Vanilla JS + Tailwind CSS)

This is a lightweight Single Page Application (SPA) built with **Vanilla JavaScript** and **Tailwind CSS**, connected to a backend API developed with **ASP.NET Core**. It supports full authentication with **JWT** and interacts with city data using secure API calls.

---

## ✨ Features

- 🔐 Login & Registration with JWT authentication
- 📦 Add, update, delete cities
- 🔄 Automatic token refreshing with access/refresh token logic
- ⚡ Fast SPA navigation without reloading the page
- 🎨 Styled using Tailwind CSS
- 🔎 City search with live results in styled cards

---

## 🔗 Backend API

The backend is built with ASP.NET Core and includes:

- JWT Authentication
- Authorization
- Token Refresh endpoint

👉 [View the Backend Code on GitHub](https://github.com/Ibrahim-Hassan74/CitiesManager-Back-End)

---

## 🔧 Technologies Used

- HTML5 & Vanilla JavaScript
- Tailwind CSS
- Axios for HTTP requests
